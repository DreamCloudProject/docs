title: 'Komponentenmodul'
description: 'Service-Helper, die du mit msm-components nutzen kannst'
---

Wenn du `msm-components` verwendest, steht dir bereits ein kleines Set an Client-Helpern zur Verfügung.

Wichtiges Verhalten:

- Die Bibliothek erzeugt die Built-in Browser-Client-Instanz intern (über `Constants.js`), du musst `MSM2.App` also nicht selbst initialisieren.
- Der globale Namespace `MSM2` muss im Browser bereits verfügbar sein, bevor `msm-components` geladen wird.
