`Utils` stellt kleine Helper-Funktionen bereit, die von vielen Components und Services genutzt werden.

## Unified WebSocket Calls

Diese Helper verwenden die Built-in Client-Instanz (exportiert als `MSM2App`), um die Unified WebSocket JSON API aufzurufen:

- `callService(beanId, scope, functionName, args, eventType?, endpoint?)`
- `callRepository(repositoryId, query, eventType?, endpoint?)`
- `updateBean(beanId, scope, payload, eventType?, endpoint?)`
