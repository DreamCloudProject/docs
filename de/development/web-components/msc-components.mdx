---
title: "Editor components"
description: "Editor-orientierte Web-Komponenten (msc-*), die zusammen mit msm-components ausgeliefert werden"
---

`msc-*` sind Lit-basierte Web-Komponenten, die hauptsächlich im MastermindCMS-Editor bzw. in Templates genutzt werden.

Viele `msc-*` Komponenten spiegeln `msm-*` Web-Komponenten. Wenn es ein `msm-*` Pendant gibt, orientieren Sie sich an dessen Dokumentation (gleicher Suffix, `msm-` Prefix).

export const msmNameFor = (mscName) => mscName.replace("msc-", "msm-")

export const descriptionFor = (mscName) => {
  if (uniqueComponents.has(mscName)) return "Editor-only component."
  return `Mirrors ${msmNameFor(mscName)} (functional overlap with msm-*).`
}

export const hrefFor = (mscName) => {
  if (uniqueComponents.has(mscName)) return `/de/development/web-components/${mscName}`
  return `/de/development/web-components/${msmNameFor(mscName)}`
}
