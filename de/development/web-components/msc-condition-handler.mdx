`msc-condition-handler` ist eine editor-orientierte Web-Komponente (Lit).

Für diese Komponente gibt es derzeit kein dokumentiertes `msm-*` Äquivalent. Siehe auch [msc-components](./msc-components).

## Usage

```html
<msc-condition-handler></msc-condition-handler>
```
