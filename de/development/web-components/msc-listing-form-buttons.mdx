`msc-listing-form-buttons` ist eine editor-orientierte Web-Komponente (Lit).

Für diese Komponente gibt es derzeit kein dokumentiertes `msm-*` Äquivalent. Siehe auch [msc-components](./msc-components).

## Usage

```html
<msc-listing-form-buttons></msc-listing-form-buttons>
```
