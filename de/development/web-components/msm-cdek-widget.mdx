title: "msm-cdek-widget"
description: "Web-Komponente msm-cdek-widget."
---

`msm-cdek-widget` ist eine Web-Komponente (Lit).

Ermöglicht die Auswahl einer Lieferoption/-adresse und feuert Events zur Aktualisierung der Bestellung.

```html
<msm-cdek-widget order-id="ORDER_ID"></msm-cdek-widget>
```

Attribute / Properties

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `delivery-type` | string | `"door"` |  |
| `order-id` | string | - |  |
| `checked` | boolean | - |  |
| `disabled` | boolean | - |  |
| `required` | boolean | - |  |

Events

| Event | detail | Wann |
| --- | --- | --- |
| `msm-delivery-calculated` | `prices`, `address` |  |
| `msm-address-selected` | `type`, `deliveryAmount`, `shippingAddress`, `metaInfo` |  |

Beispiel

```html
<msm-cdek-widget order-id="ORDER_ID">
</msm-cdek-widget>

<script>
  const el = document.querySelector("msm-cdek-widget");
  el.addEventListener("msm-delivery-calculated", (e) => {
    console.log(e.detail);
  });

  el.addEventListener("msm-address-selected", (e) => {
    console.log(e.detail);
  });

</script>
```

CSS parts

- `base`
- `label`

Slots

Keine Slots dokumentiert.

Methoden

- `validate()`

Hinweise

- Geolocation is requested only when supported by the browser.
- Geolocation is only requested on HTTPS pages (browser limitation).
- Custom events bubble.
