---
title: "msm-cdek-widget"
description: "Komponente zur Lieferauswahl auf Basis des CDEK-Widgets."
---

`msm-cdek-widget` ermöglicht die Auswahl einer Lieferoption/-adresse über das CDEK-Widget und feuert Events, die du zur Aktualisierung der Bestellung verarbeiten kannst.

```html
<msm-cdek-widget order-id="ORDER_ID"></msm-cdek-widget>
```

Attribute / Properties

| Name | Typ | Standard | Hinweise |
| --- | --- | --- | --- |
| `order-id` | string | — | Bestell-ID zum Laden von Bestell- und Verkäuferdaten. Erforderlich für die Initialisierung. |
| `delivery-type` | string | `door` | Lieferart (`door`, `office`, `pickup`). Kann vom Widget geändert werden. |
| `value` | string | — | Wert für den zugrunde liegenden Radio-Input. |
| `checked` | boolean | `false` | Markiert die Option als ausgewählt. |
| `disabled` | boolean | `false` | Deaktiviert die Interaktion. |
| `required` | boolean | `false` | Wird von `validate()` genutzt. |

Events

| Event | `detail` | Wann |
| --- | --- | --- |
| `msm-delivery-calculated` | `{ prices, address }` | Wenn CDEK Lieferpreise für eine Adresse berechnet. |
| `msm-address-selected` | `{ type, deliveryAmount, shippingAddress, metaInfo }` | Wenn der Nutzer eine Lieferoption/-adresse auswählt. |

Beispiel

```html
<msm-cdek-widget order-id="ORDER_ID" required value="cdek"></msm-cdek-widget>

<script>
  const el = document.querySelector("msm-cdek-widget");

  el.addEventListener("msm-delivery-calculated", (e) => {
    console.log("Delivery calculated", e.detail);
  });

  el.addEventListener("msm-address-selected", (e) => {
    console.log("Address selected", e.detail);
  });
</script>
```

Hinweise

- Geolocation wird nur auf HTTPS-Seiten angefragt (Browser-Einschränkung).
- Das Widget öffnet ein Popup, wenn der Nutzer “Change delivery address” klickt.
