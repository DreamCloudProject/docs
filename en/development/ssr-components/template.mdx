Some SSR components use structural sub-components to define how content is rendered.

## `<msm:template>`

The main template to render when data is present.

## `<msm:empty>`

Fallback markup when there is no data to render.

## `<msm:header>` / `<msm:footer>`

Optional sections that can be rendered around lists (for example in `<msm:foreach>` or `<msm:rest>`).
