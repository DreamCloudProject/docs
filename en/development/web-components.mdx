---

MastermindCMS UI projects can use a library of web components built with LitElement.

## Install

```shell
npm i msm-components
```

## Use in templates

After your build/bundle is included on the page, you can use custom elements directly in HTML:

```html
<msm-navbar></msm-navbar>
```
