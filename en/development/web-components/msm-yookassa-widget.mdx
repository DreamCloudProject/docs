---
title: "msm-yookassa-widget"
description: "Payment option (YooKassa) selector component."
---

`msm-yookassa-widget` renders a selectable payment option (as a radio-style item) labeled “YooKassa”.

```html
<msm-yookassa-widget value="yookassa"></msm-yookassa-widget>
```

Attributes / properties

| Name | Type | Default | Notes |
| --- | --- | --- | --- |
| `value` | string | — | Value for the underlying radio input. |
| `checked` | boolean | `false` | Marks the option as selected. |
| `disabled` | boolean | `false` | Disables user interaction. |
| `required` | boolean | `false` | Used by `validate()`. |

Events

This component does not emit custom events.

Usage

```html
<msm-yookassa-widget value="yookassa" checked></msm-yookassa-widget>
```
