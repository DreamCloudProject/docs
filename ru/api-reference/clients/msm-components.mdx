Если вы используете `msm-components`, у вас уже есть небольшой набор клиентских хелперов.

Важное поведение:

- Библиотека создаёт инстанс встроенного браузерного клиента внутри себя (через `Constants.js`), поэтому вам не нужно инициализировать `MSM2.App` вручную.
- Глобальный namespace `MSM2` должен быть доступен в браузере до загрузки `msm-components`.
