Этот модуль даёт доступ к инстансу встроенного браузерного клиента и нескольким базовым хелперам.

## Экспорты

- `MSM2App`: общий инстанс клиента, который создаёт библиотека
- `MSM2AuthHelper`: хелпер аутентификации (`MSM2.App.AuthHelper`)
- `MSM2HtmlHelper`: HTML-хелпер (`MSM2.App.HtmlHelper`)
- `MSM2ScriptHelper`: хелпер загрузки скриптов (`MSM2.App.ScriptHelper`)

## Примечания

- При использовании `msm-components` вам не нужно вызывать `new MSM2.App()` вручную.
- `MSM2` должен уже существовать в браузере в момент загрузки `msm-components`.
