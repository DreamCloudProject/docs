`RouteManager` — небольшой хелпер для клиентского роутинга.

## Экспорт

- `routeManager`

## Что он делает

- хранит список роутов и текущий активный роут
- навигация через `history.pushState`
- поддерживает динамические роуты на основе `URLPattern`
