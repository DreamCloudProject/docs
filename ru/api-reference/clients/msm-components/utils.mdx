`Utils` содержит небольшие хелперы, которые используются многими компонентами и сервисами.

## Универсальные WebSocket вызовы

Эти функции используют инстанс встроенного клиента (экспортируется как `MSM2App`), чтобы вызывать unified WebSocket JSON API:

- `callService(beanId, scope, functionName, args, eventType?, endpoint?)`
- `callRepository(repositoryId, query, eventType?, endpoint?)`
- `updateBean(beanId, scope, payload, eventType?, endpoint?)`
