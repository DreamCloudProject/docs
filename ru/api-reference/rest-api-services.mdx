## Endpoint и авторизация

Все вызовы выполняются через:

```http
POST /api/v1/bean/request
Content-Type: application/json
```

- **GUEST** — без логина, только whitelist, Bearer Token не нужен.
- **USER** — логин и Bearer Token; доступны GUEST-сервисы и методы с внутренним разрешением USER.
- **ADMIN** — полный доступ к public-методам всех сервисов, нужен Bearer Token.

Если whitelist-сервис дополнительно проверяет роль внутри метода, GUEST может получить null. Пометка **GUEST* / USER или ADMIN** означает такую внутреннюю проверку; классификация является эвристикой по исходному коду.

### Whitelist GUEST

`certificateServiceImpl`, `orderServiceImpl`, `shoppingCartServiceImpl`, `salesCatalogServiceImpl`, `sellerRegistrationServiceImpl`, `ecomRemainsSearchEngineServiceImpl`, `ecomSearchEngineServiceImpl`, `stripeServiceImpl`, `translationServiceImpl`, `messageServiceImpl`, `messageServiceSecuredImpl`, `searchHolder`, `sellerFormHolder`, `sellerSkuFormHolder`, `categoryServiceImpl`, `productServiceImpl`, `SKUServiceImpl`, `frameworkOperationServiceImpl`, `blogViewerServiceImpl`, `FCMTokenProvider`, `contentContainerRepository`, `marketingServiceImpl`, `stripeConnectServiceImpl`, `geoLocationServiceImpl`, `lexOfficeManagerServiceImpl`, `customerServiceImpl`, `profileSearchServiceImpl`, `accessManagementServiceImpl`, `pageProcessorServiceImpl`, `searchManagerServiceImpl`, `pinataServiceImpl`, `openSeaServiceImpl`, `web3ServiceImpl`

### Формат запроса

В `args` каждый аргумент передаётся объектом с ключом "0", "1" и т. д. Значение должно соответствовать типу из сигнатуры.

В каталоге `null` используется как безопасный placeholder для значения аргумента: замените его на объект DTO, строку, число или массив согласно сигнатуре конкретного метода. Для методов без параметров используется `args: []`.

```json
{"beanId":"searchManagerServiceImpl","scope":"PROTOTYPE","functionName":"search","args":[{"0":{"type":"SellerSKU","searchTerm":"","query":{"isPublishedForSale":true},"offset":0,"limit":10,"page":1,"sortName":"createdDate","sortDirection":"DESC"}}]}
```


Для USER/ADMIN добавьте заголовок:

```http
Authorization: Bearer <token>
```
