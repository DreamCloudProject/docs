---
title: "msm:fragment"
description: "Подключить и отрендерить фрагмент"
---

`<msm:fragment>` подключает другой шаблон (partial) и рендерит его в текущем месте.

## Базовый пример

```html
<msm:fragment id="mainHeader" path="main/components/navbar.html" />
```

## Атрибуты

| Атрибут | Обязателен | Значение |
|---|---:|---|
| `id` | да | Уникальный id фрагмента. |
| `path` | да | Путь к шаблону фрагмента (разрешается платформой). |
| `param` | нет | Параметры для фрагмента (строка или JSON). |
| `bean` | нет | Bean id, чтобы динамически вычислять/компилировать `path` (опционально). |
| `scope` | нет | Scope бина, если используется `bean` (`PROTOTYPE` или `SESSION`). |
| `data-lazy-render` | нет | Если `true`, фрагмент может рендериться лениво. |
| `data-lazy-load-js` | нет | Опциональная подсказка для ленивой загрузки JS. |
| `data-lazy-load-css` | нет | Опциональная подсказка для ленивой загрузки CSS. |
| `data-template-path` | нет | Путь к шаблону страницы для lazy-render. |
