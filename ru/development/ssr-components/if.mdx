---
title: "msm:if"
description: "Условный рендеринг"
---

`<msm:if>` рендерит внутренний контент только если условие истинно.

## Каркас

```html
<msm:if id="loggedIn" bean="userServiceImpl" scope="SESSION" test="isLoggedIn">
  <msm:template>
    <div>Welcome back!</div>
  </msm:template>
</msm:if>
```

## Атрибуты

| Атрибут | Обязателен | Значение |
|---|---:|---|
| `id` | да | Уникальный id условия. |
| `test` | да | Булево выражение или определение метода на бине. |
| `bean` | нет | Bean id (если `test` вычисляется на бине). |
| `scope` | нет | Scope бина (`PROTOTYPE` или `SESSION`). |
