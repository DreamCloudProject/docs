`msc-icon-link` — компонент, ориентированный на использование в редакторе (Lit).

Для него пока нет отдельного документационного аналога из `msm-*`. См. также [msc-components](./msc-components).

## Использование

```html
<msc-icon-link></msc-icon-link>
```
