`msc-listing-form-buttons` — компонент, ориентированный на использование в редакторе (Lit).

Для него пока нет отдельного документационного аналога из `msm-*`. См. также [msc-components](./msc-components).

## Использование

```html
<msc-listing-form-buttons></msc-listing-form-buttons>
```
