---
title: "msm-cdek-widget"
description: "Компонент выбора доставки на базе виджета CDEK."
---

`msm-cdek-widget` позволяет пользователю выбрать способ/адрес доставки через виджет CDEK и генерирует события, которые можно обработать, чтобы обновить заказ.

```html
<msm-cdek-widget order-id="ORDER_ID"></msm-cdek-widget>
```

Атрибуты / свойства

| Имя | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `order-id` | string | — | ID заказа для загрузки данных заказа и продавца. Нужен для инициализации виджета. |
| `delivery-type` | string | `door` | Тип доставки (`door`, `office`, `pickup`). Может изменяться виджетом. |
| `value` | string | — | Значение для внутреннего radio-input. |
| `checked` | boolean | `false` | Отмечает вариант как выбранный. |
| `disabled` | boolean | `false` | Отключает взаимодействие. |
| `required` | boolean | `false` | Используется в `validate()`. |

События

| Событие | `detail` | Когда |
| --- | --- | --- |
| `msm-delivery-calculated` | `{ prices, address }` | Когда CDEK рассчитывает стоимость доставки для адреса. |
| `msm-address-selected` | `{ type, deliveryAmount, shippingAddress, metaInfo }` | Когда пользователь выбирает способ/адрес доставки. |

Пример

```html
<msm-cdek-widget order-id="ORDER_ID" required value="cdek"></msm-cdek-widget>

<script>
  const el = document.querySelector("msm-cdek-widget");

  el.addEventListener("msm-delivery-calculated", (e) => {
    console.log("Delivery calculated", e.detail);
  });

  el.addEventListener("msm-address-selected", (e) => {
    console.log("Address selected", e.detail);
  });
</script>
```

Примечания

- Геолокация запрашивается только на HTTPS-страницах (ограничение браузера).
- Виджет открывает popup при клике по “Change delivery address”.
