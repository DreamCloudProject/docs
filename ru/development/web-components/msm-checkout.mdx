`msm-checkout` — web-компонент на Lit.

## Назначение

UI-блок для оформления заказа (checkout).

## Пример

```html
<msm-checkout order-id="ORDER_ID"></msm-checkout>
```

| Имя | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `order-id` | string | - |  |
| `calculation` | boolean | `false` |  |
| `nft-token-id` | string | - |  |
