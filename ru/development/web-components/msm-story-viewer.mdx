## Назначение

## Пример

```html
<msm-story-viewer></msm-story-viewer>
```

```html
<msm-story-viewer>
</msm-story-viewer>

<script>
  const el = document.querySelector("msm-story-viewer");
  el.addEventListener("entered", (e) => {
    console.log(e.detail);
  });

  el.addEventListener("exited", (e) => {
    console.log(e.detail);

</script>
```
