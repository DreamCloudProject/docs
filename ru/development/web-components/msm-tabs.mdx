`msm-tabs` — web-компонент на Lit.

## Назначение

Вкладки (tabs).

## Пример

```html
<msm-tabs></msm-tabs>
```

## Атрибуты / свойства

| Имя | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `activeTabTitle` | number | - | property only |
| `tabs` | array | `[]` |  |
| `application-name` | string | - |  |

## События

Этот компонент не генерирует собственных CustomEvent.

## CSS parts

Документированных `part`-слотов нет.

## Слоты

- `slot[name="button-${tab.id}"]`
- `slot[name="tab-${this.activeTab.id}"]`

## Методы

Публичные методы не документированы.
