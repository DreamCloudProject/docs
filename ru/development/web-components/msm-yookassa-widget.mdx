---
title: "msm-yookassa-widget"
description: "Компонент выбора способа оплаты (YooKassa)."
---

`msm-yookassa-widget` отображает вариант оплаты (в виде radio-элемента) с подписью «YooKassa».

```html
<msm-yookassa-widget value="yookassa"></msm-yookassa-widget>
```

Атрибуты / свойства

| Имя | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `value` | string | — | Значение для внутреннего radio-input. |
| `checked` | boolean | `false` | Отмечает вариант как выбранный. |
| `disabled` | boolean | `false` | Отключает взаимодействие. |
| `required` | boolean | `false` | Используется в `validate()`. |

События

Этот компонент не генерирует собственных CustomEvent.

Пример

```html
<msm-yookassa-widget value="yookassa" checked></msm-yookassa-widget>
```
